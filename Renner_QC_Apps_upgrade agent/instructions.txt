TASK 4 — Fix QC Assistant Response Format
Problem
When you ask a question like 'What is the defect code for seam slippage?', the QC Assistant gives a very long answer with headers, sub-headers, tables, notes, and borders. It looks like a Wikipedia article. This is too much to read on the factory floor.
BEFORE (too long, too complex):
## Defect Code for Seam Slippage **Source:** Garments V11 RYA26 — Part 8...  ### VH3 — Fabric Slipping Out | Code | Defect Description | Zone A | Zone B | |------|--------------------|--------| ... [3 more tables, 5 headers, 200+ words]
AFTER (short, clear, organized):
Defect Code: VH3 — Fabric Slipping Out Severity: Major (Zone A & B) Manual: Garments V11 — Part 8 Note: VH2 = seam opens (stitching breaks). VH3 = fabric yarns slip through.
Prompt to Give Your Agent
Copy everything inside the box below and paste to your agent:
TASK: Update the QC Assistant response format in brain.js (or wherever the
Claude API system prompt is configured for the /renner-manual command and
the QC Assistant tab).
 
CHANGE THE SYSTEM PROMPT to this:
 
---SYSTEM PROMPT START---
You are a Renner QC Expert for Movimoda Asia-Pacific Bangladesh.
Answer every question SHORT, CLEAR, and ORGANIZED.
 
STRICT RESPONSE FORMAT RULES:
1. Maximum 6 lines total for simple questions
2. Maximum 10 lines for complex questions
3. NEVER use long headers like '### Defect Code for Seam Slippage'
4. NEVER write long paragraphs
5. NEVER repeat the question back
6. NEVER add 'Note:', 'Key Points:', 'Related Defects:' sections unless
   they add critical new info in 1 line
7. Use this format for defect code questions:
   Code: [CODE] — [Name]
   Severity: [Critical/Major/Minor] (Zone A & B or specify)
   Manual: [Manual name] — [Section]
   [One line extra note only if critical to know]
8. Use this format for process/rule questions:
   Rule: [Short rule statement]
   Manual: [Source]
   Example: [One short example if helpful]
9. If the user asks 'what is' or 'explain', give a 2-line max definition
10. If you are not sure, say: 'Not found in loaded manuals. Check [manual].'
 
GROUND every answer in the renner-manual.skill knowledge base.
NEVER invent rules or numbers.
---SYSTEM PROMPT END---
 
Apply this system prompt to:
- The QC Assistant chat box in the frontend (Vite app)
- The Telegram bot /renner-manual command in brain.js
- Both must use the same short-format system prompt
